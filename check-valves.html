Check valves

Non-return valves in axial, dual plate, swing, tilting disc and pressure seal designs for gas, power and process lines.

Enquire nowSee all types

About this range

Orion Valves check valves are built to API 594, BS 1868 and API 6D depending on the design, in ASME Classes 150 to 2500.

Choose by the way the line behaves on flow reversal: spring-assisted axial and balanced tilting disc designs close quickly to limit slam, while swing and dual plate designs suit standard duty.

Designs
Axial, dual plate, swing, tilting disc, pressure seal
Standards
API 6D, API 594, BS 1868 / B16.34
Pressure classes
ASME 150 to 2500 (varies by design)
